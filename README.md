## 📌 Описание задачи

Вы — аналитик SOC (Security Operations Center). Дан временной ряд — интенсивность сетевого трафика (пакетов в секунду) за 500 условных единиц времени. 

**Цель работы:** освоить дискретное преобразование Фурье (ДПФ) для анализа временных рядов, построить спектральную модель трафика и определить наличие аномальных частотных компонент, которые могут указывать на DDoS-атаку, ботнет или скрытый канал передачи данных.

**Вариант:** 1 (`variant_01.csv`).

---

## 📂 Структура репозитория

*   `variant_01.csv` — исходные данные (временной ряд).
*   `main.py` — Python-скрипт для ручного вычисления коэффициентов Фурье (без FFT), построения графиков и расчёта ошибок.
*   `fourier_coefficients_variant_01.csv` — результаты расчёта коэффициентов \(a_k\), \(b_k\) и амплитуд \(A_k\) для \(k = 0 \dots 50\).
*   `main.tex` — исходный код LaTeX для генерации PDF-отчёта.
*   `01_traffic_series.png` — график исходного временного ряда.
*   `02_spectrum.png` — гистограмма амплитудного спектра \(A_k\).
*   `03_approximations.png` — сравнение исходного ряда с приближениями \(K=2\) и \(K=20\).
*   `04_spectrum_stem.png` — спектр в виде stem-графика.
*   `answer.md` — шпаргалка для подготовки к устному ответу.
