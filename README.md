## Цель работы

Освоить вычисление интегралов от функций комплексного переменного, проверить аналитические результаты численными методами и закрепить теоремы Коши и интегральную формулу Коши.

---

## Постановка задачи

Для заданной функции $f(z)$ и кривой $\Gamma$ необходимо:

1. Записать параметризацию кривой $\Gamma$: $z=z(t)$, $t_1\le t\le t_2$.
2. Вычислить интеграл аналитически по формуле  
   $\int_\Gamma f(z)\,dz=\int_{t_1}^{t_2} f(z(t))z'(t)\,dt$.
3. Реализовать численное вычисление интеграла.
4. Сравнить аналитический и численный результаты.
5. Для замкнутых контуров проверить теорему Коши:  
   $\oint_\Gamma f(z)\,dz=0$, если $f(z)$ аналитична внутри и на контуре.
6. Для функций с особой точкой внутри контура применить интегральную формулу Коши:  
   $f(z_0)=\frac{1}{2\pi i}\int_L\frac{f(z)\,dz}{z-z_0}$.

---

## Теоретический минимум

- Определение интеграла функции комплексного переменного как предела интегральных сумм:  
  $\int_\Gamma f(z)\,dz=\lim_{\lambda\to0}\sum_{k=1}^n f(c_k)\Delta z_k$.
- Сведение к криволинейным интегралам:  
  $\int_\Gamma f(z)\,dz=\int_\Gamma u\,dx-v\,dy+i\int_\Gamma v\,dx+u\,dy$.
- Параметрическое вычисление:  
  $\int_\Gamma f(z)\,dz=\int_{t_1}^{t_2} f(z(t))z'(t)\,dt$.
- Формула Ньютона — Лейбница для аналитической функции в односвязной области:  
  $\int_{z_0}^{z_n} f(z)\,dz=\Phi(z_n)-\Phi(z_0)$.
- Теорема Коши:  
  $\oint_\Gamma f(z)\,dz=0$.
- Интегральная формула Коши:  
  $f(z_0)=\frac{1}{2\pi i}\int_L\frac{f(z)\,dz}{z-z_0}$.

## Примеры для проверки

### Пример 1

Вычислить $\int_\Gamma z^3\,dz$, где $\Gamma$ — дуга параболы с концами в точках $A=0$, $B=1+i$.

**Ответ:** $-1$.

### Пример 2

Вычислить $\int_\Gamma (z^2+z\bar z)\,dz$, где $\Gamma$ — дуга окружности $|z|=1$, $0\le\arg z\le\pi$.

**Ответ:** $-\frac83$.

### Пример 3

Вычислить $\int_L\frac{dz}{z^2+1}$, где $L$ — окружность $|z+i|=1$.

**Ответ:** $-\pi$.
